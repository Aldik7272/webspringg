# WebSpring (Clinic Management System)

A simple Spring Boot application designed for managing medical clinic appointments.

## Tech Stack & Environment
- Java 17 (or compatible JDK)
- Spring Boot
- Gradle

## Project Structure
- Model (`Appointment.java`): Entity class representing a clinic appointment with necessary fields.
- Service (`ClinicService`): Business logic layer managing appointment operations and data handling.
- Controller (`ClinicController`): REST controller handling HTTP requests and mapping endpoints.

## How to Run the Application
1. Clone or extract the project repository.
2. Open the project folder (`WebSpring`) in IntelliJ IDEA.
3. Run the main application file: `ClinicApplication.java`.
4. Access and test the application endpoints via your browser or Postman.
